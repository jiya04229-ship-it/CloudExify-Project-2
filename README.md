📌 Project Overview

This project was developed as part of the CloudExify Cybersecurity Internship – Month 1. It focuses on the practical implementation of cryptography, password security, secure authentication, and data protection using Python.

The project demonstrates how modern security techniques can be applied to protect user credentials and sensitive information from unauthorized access.

🎯 Key Objectives

Understand fundamental concepts of cryptography and password security.
Implement secure password hashing using bcrypt.
Compare SHA-256 and bcrypt for password protection.
Encrypt and decrypt sensitive information using Fernet.
Develop a secure registration and login system.
Understand the importance of HTTPS and SSL/TLS.
Apply cybersecurity best practices through practical testing.
🛡️ Key Implementations

1. Password Hashing with bcrypt
Implemented bcrypt to securely hash passwords before storage. The system uses salting and password verification to improve credential security.

2. SHA-256 vs bcrypt
A practical comparison was performed to demonstrate the differences between SHA-256 and bcrypt and why bcrypt is more appropriate for password storage.

3. Fernet Encryption
Implemented symmetric encryption and decryption using Fernet. A wrong-key scenario was also tested to verify that unauthorized decryption is prevented.

4. Secure Login System
Developed a Python-based authentication system supporting user registration and login verification. Passwords are stored as bcrypt hashes rather than plaintext.

5. HTTPS & SSL/TLS Verification
Verified a secure HTTPS connection and examined SSL/TLS certificate information through the browser to understand secure communication over the internet.

6. Security Testing
The implemented modules were tested for password hashing, authentication, encryption/decryption, password storage, HTTPS security, and SSL/TLS certificate validation.
